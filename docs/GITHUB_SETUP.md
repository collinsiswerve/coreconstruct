# GitHub handoff

Repository: https://github.com/collinsiswerve/coreconstruct

Application source, lockfile, tests, migrations, CI and documentation belong here. Database records, uploaded proof, identity data, exports, environment files and tokens do not. The ignore rules exclude operational data and build/runtime folders.

The repository was public when this handoff was prepared. The code upload was explicitly requested. The hosted Site remains owner-private; source visibility and application data access are independent.

Use issues for observed failures with reproducible fictional inputs, expected/actual results and device/browser details. Do not attach national IDs, client financial documents, raw production backups or credentials to public issues. Redact screenshots before posting.

CI checks future pushes/pull requests. A green local run does not claim that GitHub Actions has already run. Live publishing remains a separate deployment operation.
